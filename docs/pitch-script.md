# Solstream — 1-minute pitch script

**0:00-0:15**

Freelancers wait weeks to get paid. Streamers and API users face the same problem. Traditional lump-sum payments create trust issues and cash flow problems.

> フリーランサーは支払いを何週間も待ちます。ストリーマーやAPI利用者も同じ問題を抱えています。従来の一括払いは信頼の問題とキャッシュフローの問題を生み出します。

**0:15-0:35**

Solstream solves this with pay-per-second streaming on Solana. A payer sets a rate, token, and duration. Funds accrue continuously, and both sides watch the balance grow live. Recipients withdraw anytime, no waiting.

> Solstreamはこれを、Solana上の秒単位のストリーミング決済で解決します。支払う側がレート、トークン、期間を設定すると、資金が継続的に蓄積され、両者がリアルタイムで残高を確認できます。受け取る側はいつでも引き出せます。

**0:35-0:50**

We built this using Anchor and Rust for the on-chain program, and React with the Solana wallet adapter for the dashboard. Solana's sub-second finality and near-zero fees make per-second payments actually work.

> オンチェーンプログラムはAnchorとRustで構築し、ダッシュボードはReactとSolanaウォレットアダプターで作りました。Solanaの秒未満のファイナリティとほぼゼロの手数料が、秒単位の支払いを実現可能にします。

**0:50-1:00**

Next, we're adding stablecoin streams, freelance platform integrations, and subscription templates for SaaS billing. Solstream makes payments as continuous as the work itself.

> 次はステーブルコインのストリーム、フリーランスプラットフォームとの連携、SaaS課金向けのサブスクリプションテンプレートを追加します。Solstreamは支払いを仕事そのものと同じように継続的にします。
